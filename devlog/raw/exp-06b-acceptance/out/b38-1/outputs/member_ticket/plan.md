# Task

在 http://localhost:5173 這個活動報名網站上,用一般會員帳號登入(帳號密碼寫在
<lab>/seed.sql 第 2 行的註解裡,用
member 那個 → member@example.com / password123),到活動列表進入「秋季音樂會」,用
「一般」票種保留一個座位,然後確認訂單,最後到「我的票券」確認看得到這張票,而且
畫面上的金額要跟資料庫裡的票價對得上。回報:座位號、訂單金額、票券頁顯示的內容。

(資料庫依據 seed.sql:tt-general「一般」price_cents = 100000,容量 60。)

# Critical Points
- [ ] CP1: 以一般會員帳號 member@example.com / password123 成功登入(畫面上有登入後狀態,例如暱稱「小明」/ 登出選項)
- [ ] CP2: 由活動列表進入「秋季音樂會」活動頁(標題/名稱確認)
- [ ] CP3: 選擇「一般」票種、數量 = 1,保留一個座位(畫面上顯示選中的票種與數量)
- [ ] CP4: 確認訂單成功(有訂單確認畫面/成功訊息,含座位號)
- [ ] CP5: 「我的票券」看得到這張票(顯示活動名「秋季音樂會」、票種、座位號)
- [ ] CP6: 票券頁/訂單金額與資料庫票價一致(seed.sql tt-general price_cents=100000 → 畫面上 NT$1,000.00)
- [ ] CP7: 記錄並回報最終資料:座位號、訂單金額、「我的票券」頁顯示內容(寫入 final_script_log.txt)
