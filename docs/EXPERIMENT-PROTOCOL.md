# 實驗紀律

> v3 在這件事上失敗過:文章寫「我的 schema 8/25 就寫好了,存檔標了日期」,
> 但 repo 第一個 commit 是 9/3 05:19,AI 版 05:28 —— **差 9 分鐘**,
> 而且拿不出可查的證據。一個專門打「宣稱未驗」的系列,不能自己留一句查不到的 SHA。

## 順序(不可逆)

```
1. 我自己寫             → commit,message 明寫「AI 尚未介入」
2. 開乾淨 session       → AI 出一版
3. AI 版另外 commit     → 原始輸出存 devlog/raw/
4. 比對差異             → 寫進文章
```

**兩個 commit 的先後就是證據,讀者查得到。**

## 適用對象

| 對象 | 文章 |
|---|---|
| schema | Day 22 |
| 金額引擎與折扣順序 | Day 25 |
| 時間判定 | Day 26 |
| 併發(超賣 / 座位 / TTL) | Day 27 |

## 無菌室 session 的規則

開實驗 session 時**不可以**給它:

- `CLAUDE.md`
- `2026-impl-spec.md` 第三節(七個陷阱)
- 這份檔案
- 任何提到「用整數存金額」「時間要當參數」的東西

> 你知道要測什麼,AI 不能知道 —— 否則它不是在解題,是在應付考試。

## 記錄格式

`devlog/raw/exp-<id>-<topic>.md` 存**原文**,不要轉述:

```markdown
# 實驗 <id>:<主題>
日期 / 模型 / 有沒有給 CLAUDE.md

## 我下的 prompt(逐字)
## 它交出來的(原文貼上,不要摘要)
## 我的對照版本
## 差異
## 誰對,以及為什麼
```

**AI 的錯誤輸出要原文貼上** —— 轉述過的錯誤沒有說服力。
